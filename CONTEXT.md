# Shared language

**TurnDirective** — A bounded, locally constructed instruction for one composable sales turn. It combines the selected move, approved profile strategy, verified call evidence, and—only when the move is underspecified—one methodology framework. It is not model output or raw source context.

**Guided strategy** — Editable profile data that specifies the objective, approach, and avoidances for a composable move. It constrains wording while the model adapts it to verified call context.

**Methodology compiler** — Deterministic local logic that converts one selected methodology framework and a guided strategy into a TurnDirective for an underspecified or novel objection.
